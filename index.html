TeachSpeech

Live class captions and lesson notes for Mac.

Download for Mac

Version 0.1.2, 11 MB

  • Needs an M-series Mac with macOS 14.4 or later.
  • On macOS 14, click a sentence and choose Translate for Vietnamese. Live Vietnamese captions need macOS 15.
  • Unzip it and drag TeachSpeech to Applications.
  • If macOS blocks it, go to System Settings > Privacy & Security > Open Anyway.
  • If macOS says it is damaged, run xattr -cr /Applications/TeachSpeech.app in Terminal.
  • On first launch, download the speech models (1.3 GB) on Wi-Fi.
  • From version 0.1.2, new versions appear on the home screen. Click Update to install them.
